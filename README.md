# Forma Studio

Visual application specification and composition environment for Forma.

Repository bootstrap is tracked in GitHub issue #1. Full governed project state is established on the bootstrap branch before implementation work begins.

## Requirements

See `REQUIREMENTS.md` for the normative shared-capability contract. Forma Studio MUST dogfood Forma for its own interactive UI, MUST adopt Aegis when operational boundaries are introduced, and MUST adopt Folio when printable/PDF/paginated document composition or Folio authoring/testing enters scope.
