# AI assistant discovery and typed email authoring in Forma Studio
Date: 2026-11-23. Proposed only.

Studio must consume Forma's version-pinned assistant metadata for every component, property, input, event, state, layout and email block. Provide "Explain", "Help configure", error correction, valid value examples, dependency explanation, contextual help, AI proposed edits with diff and safe preview. Distinguish design intent from runtime permissions; Studio must never grant domain authority or silently publish.

For email, offer visual blocks plus optional constrained template syntax backed by one typed AST, token explorer, static type errors, conditional branch preview, bounded collection preview, sponsor terminology, localization and protected legal fragments. AI must use approved token catalog and synthetic data, preserve required disclosures and submit edits to the normal approval lifecycle. Roundtrip and migrations cannot lose content. Expose unavailable capability gaps rather than private Studio implementations.

Validate mobile/keyboard authoring, accessibility, unauthorized token discovery, prompt injection, preview/publish separation, and public Forma version parity. No implementation claimed.
