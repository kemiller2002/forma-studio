# Contextual AI assistance pattern authoring and preview
Date: 2026-11-23. Proposed requirements only; no implementation.

Forma Studio must support composing and validating public Forma contextual-assistance patterns: inline field help, assistant drawer/mobile workspace, evidence annotations, uncertainty/freshness, typed proposal/diff, confirmation/approval status and grouped notification views. Simulate role/sponsor contexts with synthetic data, including disabled, Unknown, stale, restricted, model unavailable, approval pending and critical hold states.

The design editor must distinguish presentation simulation from real authority and must not silently publish configuration. Validate keyboard/touch/focus/zoom/mobile and nonobscured mandatory notices. Use pinned public Forma components, expose missing capabilities as gaps, and preserve versioned deterministic export. No private Studio-only assistant UI primitives.
